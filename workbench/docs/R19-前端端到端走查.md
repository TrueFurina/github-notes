## 四、发现一处命名不一致（未改，待你决定）

项目名称有 **3 种叫法，出现在 6 处**：

| 位置 | 名称 |
|---|---|
| `README.zh.md:1` | 物理学科智能排课选课**智能体系统** |
| `frontend/index.html:7`（浏览器标签） | 物理学科智能排课选课**系统** |
| `frontend/src/App.tsx:962`（页面 H1） | **物理实验调课辅助** |
| `backend/app/main.py:114`（FastAPI title） | **物理实验调课辅助系统** |
| `backend/app/main.py:1`（模块 docstring） | **物理实验调课辅助系统** |
| `backend/app/main.py:232`（`/` 返回） | **物理实验调课辅助系统 API** |

### 影响

- 浏览器标签显示「智能排课选课系统」
- 页面大标题显示「物理实验调课辅助」
- `/docs` 的 API 文档标题是「物理实验调课辅助系统」

**同一个系统，三个名字**。评审或新用户会困惑：这到底是不是同一个项目？

### 为什么没改

这是**产品命名决策**，不是技术缺陷。选哪个牵涉产品定位：

- 「智能体系统」强调 AI 能力（但规则引擎才是主力）
- 「智能排课选课系统」中性、准确
- 「物理实验调课辅助」最贴近实际用途（调课辅助），但显得格局小

**已向你确认过，未收到选择，故保持现状。**

### 建议

如果只是想让它们一致，最小改动是**把 H1 和后端 title 对齐到 `index.html` 的「物理学科智能排课选课系统」**（去掉「智能体」三字，因为规则引擎承担主要逻辑）。
