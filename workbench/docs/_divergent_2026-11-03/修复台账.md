# 审计修复台账

> 12 轮审计，10 个仓库，17 条修复。这份文档回答一个问题：
> **报过的缺陷，现在还在修好的状态吗？**

---

## 一、为什么需要它

审计报告有一个天然缺陷：**它记录的是"我修了"，而不是"现在还修着"。**

本轮开始时我做了一次核查，结果值得记下来：

- 大部分修复都还在，因为都在本地副本里，没人动
- 但**有一条我压根没修**——DevRadar 的客户端 `client.py`

上一轮（R97）我修了 `server.py` 的跨 chunk 解码与无上限缓冲，然后收工了。
`client.py` 有一个**逐字相同**的接收循环，我完全没看。

发现它的不是我又读了一遍代码，而是 R102 写的静态探针扫出来的。

**这说明一件事**：报告的完成感会骗人。"这项已修复"写进文档之后，
就再没有人回去验证；而副本会被重下、被同步成上游版本、被同事覆盖。

## 三、两种检查，必须都跑

### 1. 代码在位（`fix_ledger.py`）

每条断言两件事：
- **必须出现**的修复标记
- **必须消失**的缺陷代码

第二条是关键。只看"修复标记在不在"会漏掉这种情况：代码里加了个 `allow_network`
参数，但主路径根本没传下去——参数在、行为没变。

**实测**：把 DevRadar 服务端的解码改回缺陷版，台账精确报出那一条，且不牵连同仓库的另一条。

### 2. 修复仍然有效（`--verify`）

修复代码在位 ≠ 行为正确。所以每条配一条**可执行的验证**：

```
✅ [audit-devradar]  边界回归: 11 passed
✅ [audit-harness]   网络隔离: 8 passed
✅ [audit-skillware] 注入检出: 15 passed
✅ [audit-marl]      k 重用: 10 passed
✅ [audit-aerorider] 结果一致性: 6 passed
✅ [audit-agi]       元数据守卫: 全部通过
✅ [audit-mcphub]    三方一致性: 结构性漂移 0 处
```

```bash
python tools/fix_ledger.py            # 只看代码在不在
python tools/fix_ledger.py --verify   # 顺便跑测试确认行为没回归
```

## 四、这一轮我自己犯的错（四次）

台账本身写了不到 200 行，但我在这上面连续出错了四次，每一次都值得记：

| # | 错误 | 怎么发现的 |
|---|---|---|
| 1 | 把 marl 的 `security_guard.py` 误记成 xihu 的 | 台账报"文件不存在"，人工核对 |
| 2 | 回归标记写 `buffer += chunk.decode(...)`，被**注释里的引用**命中 | 台账报"缺陷代码回来了"，但 grep 发现命中的是注释 |
| 3 | 改用 `tokenize` 剥注释，**没剥 docstring** | 同上，命中的是 docstring 里的引用 |
| 4 | 移动函数时把 `main` 复制成两份、`VERIFY` 表被切掉 | `NameError` |

第 2、3 条是同一个错误的两次迭代：**我的判据把"注释里提到旧写法"判成了"缺陷回来了"**。

而"注释里保留旧写法"恰恰是好事——它留下了现场，让后来人知道这里改过什么。
一个正确的判据应该**奖励**这种写法，而不是惩罚它。

最终实现：AST 定位所有 docstring 节点按行清空，再逐行剥行尾注释，剩下的才是"真正的代码"。

**这和我在 R101 批评别人的"判据太粗"是同一个错误。** 写判据的人，最容易犯自己正在批判的毛病。

## 五、可复用的三条

1. **每条修复都要有"缺陷必须消失"的反向断言**
   只查"修复标记在"会漏掉"参数加了但没用"。

2. **反向断言必须剥注释再比**
   否则注释里的历史说明会把判据变成永久红灯，然后被人关掉——那时它连装饰都不是。

3. **"修好了"和"还是好的"是两件事**
   前者是报告里的一句话，后者需要一个能重跑的命令。


**这 17 条对应的原始缺陷**：
- 2 条会导致**私钥可推导**（marl 的 k 重用）
- 1 条会让**注入检测形同虚设**（skillware 默认档）
- 2 条会让**沙箱里的数据外泄**（octop 网络未隔离）
- 2 条会让**消息静默丢失**（devradar 两侧）
- 3 条会让**没验过的结果被当成通过**（distillery）

这些都是"代码能跑、测试能过、CI 是绿的"的缺陷。
它们值一份能重跑的台账。
