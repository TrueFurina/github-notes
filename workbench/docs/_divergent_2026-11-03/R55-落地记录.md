|---|---|

早前（R44 那轮）记的是「11 次 = 7 检出 / 4 存活」，两者一致。**p 大约 2/3，不是 1。**

M42 的定义（`tests/mutation_check.py` 索引 41）：

```
desc: 片间不回填班级占用（新方案撞绪论课）
file: app/engine/auto_scheduler.py
old:  '                extra_class_busy=class_busy,'
new:  '                extra_class_busy=None,  # MUTANT: 不回填班级'
-k  : chunked_schedule or chunk_report     FILES: tests/test_chunk_backfill.py
```

根因链（本轮实测确认）：`app/engine/auto_scheduler.py:362` 只有一句 `status = solver.Solve(model)`，
**没有** `random_seed` / `num_search_workers` / `max_time_in_seconds`（全文件 grep 这三个词各 0 次，
文件 922 行）。CP-SAT 默认多线程搜索，在多个同等最优解之间挑选是不确定的 ⇒
"新方案是否恰好撞上绪论课"这件事本身就有时有、有时没有 ⇒ 变异被检出还是存活，取决于这一次求解挑了哪个解。

⇒ **本轮的 `55/56` 与 R54 记录的 `56/56` 不矛盾，但"56/56"这个数字不该再单独写。**
正确写法是：**"55/56 稳定检出，M42 概率性（p≈2/3），12 次实测 8 检出 4 存活"**。
