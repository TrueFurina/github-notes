## 2. 为什么这一族必须**整块**搬

导出是同一份数据的多个投影，共享一套字节缓存 + 一套预热 + 一套门禁。只搬一半的后果是
**两份 `_EXPORT_CACHE`**：功能 100% 正确、缓存用例全绿，只有命中率腰斩 —— 因为每一份内部
都自洽。所以守卫判的是 `is`（同一个对象），不是"内容相等"。

## 5. 一条**假红**，与它暴露的仪器问题（第 16 条）

全量跑第 800 条时红了一条与本轮**无关**的用例：

```
test_land_undo_waiting_on_write_lock_does_not_stall_heartbeat
AssertionError: 撤销只用了 0.297s —— 它没等在写锁上，这条用例证明不了任何事情
assert 0.297 >= 0.3
```

- **不是锁退化**：单跑连过 3 次，每次 1.44s。
- **是前置断言余量不足**：`threading.Timer(0.35, release.set)` 在 `_run_with_heartbeat`
  **之前**起跑，等撤销真正去抢锁时计时已走掉一段；全量负载下实测走掉 **53ms > 50ms 余量**。
- **修法**：持锁 0.35s → **0.6s**，断言 0.3s → **0.45s**（余量 150ms ≈ 观测最坏值的 3 倍）。

第 16 条仪器教训：**前置断言的余量必须大于被测路径的启动开销**。
"反证失败"型断言本质是在测仪器；仪器自身开销没算进去，它就会在被测对象完全正常时报警。
