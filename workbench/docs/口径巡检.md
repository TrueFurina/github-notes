## 三、查了三件事，都没发现新缺陷

这轮**没找到新缺陷**，但过程有信息量：

### 3.1 `has_truth` 的命名陷阱

扫描"无真值判定"时，`eval/corpus.py:has_truth` 返回 `True`，而其他 4 处返回 `False`。

一度以为是方向相反的错误。查完发现：**`has_truth` 是正向谓词**
（"是否有真值" → `True` 表示有），与 `not truth → return False` 方向不同是正常的。

**我的扫描把谓词名当成了判定结果。** 这类"命名语义与判定方向"的耦合，
静态扫描没法自动判——只能人工确认。

### 3.2 sha256 口径确实共用

`eval/corpus.py` 里的 `_SHA256_RE` 是从 `eval/cases.py` **import 进来的**，
不是自己定义一份。两处口径天然一致。

而且 `has_truth` 的 docstring 还记着这个约束的理由：

> 必须是合法 64 位十六进制 sha256，否则只是占位/格式串，不可校验。
> 非 hex 占位若计入分母，`expected_sha256=None` → `flag_matches` 恒 False，
> 既膨胀分母又制造"永久不可解"假象。

**这条注释本身就是口径一致性的说明**——它解释了"为什么必须共用"。

### 3.3 贪婪正则只剩一处，且安全

R107 修完后，8 处非贪婪，**唯一剩的贪婪是 `dasctf.py:714`**：

```python
_FLAG_WRAPPER_RE = _re.compile(r"^(?:flag|FLAG|ctf|CTF|DASCTF|dasctf)\{(.+)\}$")
```

**带全串锚定 `^...$`**，贪婪不会跨出结尾的 `}`——安全。

## 四、交付：`tools/check_concept_parity.py`

| 检查 | 内容 |
|---|---|
| **C1** | 判定方向：同一概念的正/反判定，返回值符号是否一致 |
| **C2** | 正则口径：贪婪 vs 非贪婪（**锚定场景单独归类**） |
| **C3** | 复用关系：是否 import 同一个真值源，而不是各自复制 |

### 一个关键设计：锚定豁免

第一版报"两种写法并存：贪婪 1 / 非贪婪 8"，红灯。

但那一处是 `^...$` 锚定的安全写法。**不豁免的话这条会永久红灯，然后被人关掉。**

修法是把贪婪再分两类：

```python
if is_greedy and ("^" in line or ")$" in line or "}$" in line):
    anchored.append(...)   # 安全，单独计数
elif is_greedy:
    greedy.append(...)     # 危险
```

输出变成：

```
【flag 内文提取】9 处
  ✅ 全部非贪婪（8 处）
     （另有 1 处贪婪但带全串锚定，安全）
```

**不是"放过它"，是"说清它为什么安全"。**

### 4 项自检

```
[PASS] T1 非贪婪被正确识别
[PASS] T2 贪婪被正确识别
[PASS] T3 变异：混合写法 → 贪婪 1 / 非贪婪 1
[PASS] T4 注释被正确忽略
```

T4 很重要：注释里常常引用"原实现是贪婪的"，不剥注释会把历史说明当成现存缺陷。
（R107、R103 都踩过这个坑。）

## 五、这轮为什么没找到缺陷，仍然值得做

前三轮（R113 检测器 / R114 个案 / R115 不变量）都产出了缺陷。这轮没有。

但它是**另一种产出**：

| 工具 | 回答什么 | 类型 |
|---|---|---|
| `check_silent_drop` | 代码里有没有"固定列表漏成员"的**形态** | 模式匹配（有误报） |
| `check_table_invariants` | 这张表的数字**对不对** | 数学事实（非黑即白） |
| **`check_concept_parity`** | 同一概念**有几处**实现、一致吗 | **分布测绘** |

第三个是**测绘**，不是判定。它的价值在于：**下次有人改口径时，能立刻看到"还有几处"。**

R107 我改 4 处贪婪正则时，是靠 `grep` 反复找的。如果当时有这个巡检，
一次就能看到全部 9 处、以及哪一处带锚定。

## 七、三条可复用的

1. **"修了几次"是信号，不是成绩。**
   同一主题修 6 次，说明缺的不是第 7 次修复，而是一层能看到全局的检查。

2. **谓词名会骗过静态扫描。**
   `has_truth` 返回 `True` 不代表方向反了——它是正向谓词。
   命名语义与判定方向的耦合，机器判不准，必须人工确认。

3. **豁免要说清理由，不能只是不报。**
   锚定的贪婪写成"跳过"和写成"另有 1 处贪婪但带全串锚定，安全"，
   对下一个人的价值完全不同。前者是噪音，后者是知识。
