## 三、推送

```powershell
$env:GITHUB_TOKEN="ghp_xxx"        # 需 repo scope
cd D:\github\audit-notes-fresh
python push-notes.py --dry-run     # 先看预检结论
python push-notes.py
```

脚本行为：

| 阶段 | 检查 | 失败时 |
|---|---|---|
| 预检 1 | 远端 HEAD（不强制等于某个值，只打印） | — |
| 预检 2 | 两个既有文件是否已含我的标记 | 提示"将以本地整体覆盖，请确认" |
| 写入 | 3 blob → 新 tree（`base_tree`）→ commit | 出错即停 |
| 推送 | PATCH ref，**`force: false`** | 远端已前进时**失败**，不覆盖 |
| 复核 | 读回远端 blob，逐字节比对 sha256 | 不一致即非 0 退出 |

**不做自动 rebase**：那需要判断别人的改动是否与我的冲突，脚本没有那个判断力。
