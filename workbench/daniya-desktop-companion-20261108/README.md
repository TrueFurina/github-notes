# 达妮娅 · AI 桌面伴侣

<img src="src/ui/web/danya/av/stand.png" width="180" align="right" alt="达妮娅">

她住在这台电脑上：能听你说话、能出声、能看着你的屏幕接话，也能记住你。
不是网页里开一个标签页，而是一个**桌面上一直在**的角色。

> 当前版本 **0.2.0**（build 20261018）· Windows 10 / 11（64 位）· MIT License

**两条设计取舍，先说明白：**

- **本地优先**。API Key 只存在这台电脑的 `config.yaml` 里，聊天内容直接发给你选的模型服务商，
  不经过任何中转服务器。代价是你要自己准备一个 Key——所以第一版把「配 Key」从引导里删掉了，
  改成**在他真正想说话的那一刻**才出现（见下面「她还没接上大脑」）。
- **看得见的采集**。看屏不是后台偷偷截，桌宠右下角有一个点：青=正在看、琥珀=隐私模式、不亮=关着。
  网银 / 密码管理器 / 支付页面**整帧不采集**（判定在抓屏之前，不是抓完再丢）。

## 快速开始

### 路线 A · 用安装包（给测试用户）

见 [`docs/使用指南_内测版v1.0.md`](docs/使用指南_内测版v1.0.md)。里面有 4 个必须避开的安装坑
（装到盘根 / 中文路径 / 杀软拦截 / 蓝色警告），照着走能省一小时。

> ⚠️ **v1.0 安装包是旧流程**：引导页会要求粘贴 Key。仓库里的代码已经是新流程（不问 Key）。
> 两者不是同一个版本，别拿指南去对代码。

### 路线 B · 从源码跑（给开发/联调）

需要 **Python 3.12**（开发/验包基线；3.11 未测，3.13+ 部分依赖还没有 wheel）。

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
cp config.release.yaml config.yaml     # 出厂模板；源码仓版多为 ${VAR} 环境变量引用，交付包版 API Key 字段留空
.venv/Scripts/python main.py --doctor  # 先自检，别等启动失败才排查
.venv/Scripts/python main.py
```

漏了 `cp` 那一步也不会崩：`main.py` 发现 `config.yaml` 不在、旁边有 `config.release.yaml`
时会自己起一份并打一行提示（2026-11-04 验包时补的——原来这里直接抛
`FileNotFoundError`，窗口一个都不出现，只落一个 crash 日志）。

> 📦 **交付包说明**：这条自愈依赖 `config.release.yaml` 模板存在。本交付包**已随包带上该模板**
> （`src/config.py:498 CONFIG_TEMPLATE_NAMES` 的第一个候选），所以误删 `config.yaml` 后再次启动
> 会自动从模板重建，`ensure_config_file()` 返回 `created`，窗口正常出现，不需要重新解压安装包。
> 2026-11-08 实测：缺配置 → `created`、生成文件与模板逐字节一致（`force_first_run=true`、
> `app.version=0.2.0`）；已有实配 → `exists`，**模板永不覆盖用户实配**；完全没有模板 → `missing`
> 且 `SystemExit(2)`（这是源码仓缺模板时的旧行为，交付包已不落入此分支）。
>
> 仍然不要手删 `config.yaml`：重建出来的是出厂态，之前填的 Key、角色、开关都会丢。
>
> 🔒 **打包侧**：`config.release.yaml` 必须固化进打包清单。本包曾漏发过一次，才有了上面那段
> 失效的自愈说明。发布前跑 `python/python.exe tools/check_delivery.py`，漏发会直接 FAIL。

`--doctor` 在干净环境下的基线：**16 PASS / 3 WARN / 0 FAIL**（交付包实测，2026-11-08）。
3 个 WARN 分别是：`config.yaml` 是出厂默认值但 `data/` 有使用痕迹 / `Uninstall.exe` 无内嵌签名 /
主聊天与视觉模型未填 `api_key`。软件正在运行时会多一条「端口被占用」WARN，属正常，无需处理。

其他入口：`--no-gui` 只起控制台、`--pet-backend {auto,webview,shell}` 指定桌面壳、
`--config <path>` 换配置文件、`run_webui.py` 单开角色管理界面。

## 她还没接上「大脑」的那一下

首启只有两步：**建角色 → 体检**。不问 Key，也不摆一张表拦人。

代价是：他打完第一句话、点发送，会被挡下来。所以补偿做在**那一刻**——
输入框上方浮出一个小卡片，说清「她还没接上大脑」，两个出口（去配一个 / 稍后），
刚才那句话还留在输入框里。语音路径同样接了（副文换成「配好之后直接开口说就行」）。

为什么不做成顶部常驻条：它出现在**错误的时刻**。刚进桌面时用户没有聊天意图，看到了也不会动；
等他真想说话，眼睛早把它过滤掉了。调研的 28 个消费级产品里，没有一个靠顶部条成功的。

## 隐私与数据

- **Key**：存本机 `config.yaml`，可选 DPAPI 加密（仅本机可解）；模板里用 `${ENV_VAR}` 引用的不落盘
- **聊天内容**：直接发给你选的模型服务商，**不经过我们**（全仓外发域名里没有任何第一方服务器）
- **看屏**：敏感窗口整帧不采集；隐私模式全停；随时可在设置里关掉
- **聊天记录 / 记忆 / 通话录音**：都在 `data/`，仅本机可见，卸载时需手动删
- `config.yaml`、`data/`、`logs/`、`.venv/` 全部在 `.gitignore` 里，**从第一次提交起就没进过仓库**

## 质量是怎么守的

```bash
python tools/check_all.py     # 57 道闸门（截至 2026-10-20），约 4 分钟
```

> 📦 **交付包用户看这里**：上面这套 CI（`check_all.py` / pytest / `src/tests` 脚本式自检）依赖
> 源码仓的开发期文件，**不随交付包分发**，包内跑不了。交付包可用的是这几个（已实测全绿，约 30s）：
>
> ```bash
> python/python.exe tools/check_delivery.py              # 清单/资源树/源码闭包/文件实体/依赖/模板/密钥/自愈，7 PASS / 1 WARN / 0 FAIL
> python/python.exe tools/check_delivery.py --smoke      # 追加一项：真跑一次包内解释器做导入冒烟，8 PASS / 1 WARN / 0 FAIL
> python/python.exe main.py --doctor                    # 一键自检（干净环境下 16 PASS / 3 WARN / 0 FAIL；
>                                                       # 若有旧实例/端口占用会多 1 条 WARN，属正常）
> python/python.exe -m compileall -q src main.py tools   # 语法硬门禁
> python/python.exe -m src.proactive_pack.selftest       # 202 PASS / 0 FAIL
> python/python.exe -m src.agent_pro.selftest            # 39 PASS / 0 FAIL
> ```
>
> `tools/check_delivery.py` 是**发布前闸门**，五层覆盖防「清单没写就恒绿」：
> 36 个必备文件（逐条注明证据来源）、6 棵资源子树的文件数下限、AST 扫
> `src/**/*.py` 的 145 个 `src.*` 导入目标逐个解析（不用手工罗列 200 个源码文件），
> 外加「文件实体」校验——文件**在**不等于**能用**，用 PE `MZ`、HTML 结构标记、
> RIFF/WAVE、非空文本、YAML 映射五类魔数挡住 0 字节/截断/错格式的占位包；
> 以及「依赖完整」校验——用 `site-packages/*.dist-info` 核对 `requirements.txt`
> 的核心 12 项与重要 13 项是否真的装进了内置运行时（核心缺 → FAIL，重要缺 → WARN），
> 挡住「改了 requirements 但没重装进内置运行时」这类要等用户 import 才暴露的问题。
> 此外校验出厂模板是 `force_first_run=true` 且与实配同版本、模板里没有明文 API Key，
> 并在临时目录复验「误删 `config.yaml` 能自愈」——**验的是 `--root` 目标包自己的
> `src/config.py`，不是闸门所在包的实现**（第九轮修过一次 `--root` 假绿）。**打包完成后跑它**，
> 就能挡住「模板又漏发 / Web UI 整棵没打进包 / 某个被 import 的模块漏发 / 新包自愈逻辑被改坏 /
> 文件在但是 0 字节 / 核心依赖没装进包」这类回归；`--root <目录>` 可验另一份包，
> `--json` 供流水线读取（有 FAIL 即 exit 1）。
> 它做过 32 个变异场景验证（含 `--root` 命令行端到端），全部按预期变红，
> 且 `${VAR}` 引用、已知缺件、重要依赖缺、只有模块无元数据、`isolated=0` 等按预期只 WARN，不误报。
> 当前唯一 WARN 是已知缺件 `src/ui/quota_guard.py`（设置页额度角标静默不显示，P2，
> 非启动阻断；详见一页版结论）。**任何新的缺失模块会直接 FAIL。**
>
> `--smoke` 是**可选**的第 9 项：前面 8 项全是静态判据，证明不了「内置解释器真能跑」——
> 位数不匹配、UCRT 缺失、杀软拦 `python.exe`、site-packages 里只有目录没有可加载的 `.pyd`，
> 这些只有真跑一次才知道。开启后闸门会执行**目标包内的 `python.exe`**（只跑一段固定的
> import 探针，不读配置、不写文件、不联网），默认关闭以保持纯只读。只对自己打的包用；
> `--root` 指向来路不明的目录时**不要**开。
>
> 📄 一页版结论（发布流程直接看这个）：[`交付结论_一页版_2026-11-08.md`](交付结论_一页版_2026-11-08.md)；
> 十二轮完整取证见 `质检基线_2026-11-08.md`。
>
> 「文档地图」里的 `AGENTS.md` / `CHANGELOG.md` / `docs/` / 各份调研报告也仅在源码仓，交付包不含。

不是「跑一遍没报错」就算过。每条闸门都做过**变异验证**：故意把实现改坏，确认它真的会红，
再还原。这一条写在 [`AGENTS.md`](AGENTS.md) 第二条里，是这个仓库最贵的纪律——
本项目抓到过的假绿至少有六种形态（断言被自己的注释满足、被同页无关代码满足、
靠残留产物通过、判据在改前改后都不存在……），每一种都是"测试全绿但功能是坏的"。

新增能力请同时补：闸门 + 变异 + CHANGELOG 明细（问题 → 改动 → 验证证据）。

### 本地跑一遍 CI 同款检查

CI 是三条腿，任一红即不通过（[`ci.yml`](.github/workflows/ci.yml)）：

```bash
python -m pip install -r requirements-test.txt   # 只装测试依赖，不装整套运行依赖
python -m compileall -q src main.py tools        # 腿 1：语法（硬门禁）
python -m pytest src/tests -q                    # 腿 2：pytest
```

腿 3 是 `src/tests` 下的**脚本式自检**，要逐个跑：

```powershell
Get-ChildItem src/tests/test_*.py | ForEach-Object { python $_.FullName }
```

它们不是 pytest 用例——`import` 阶段就会跑完整检查并 `sys.exit(1)`，混进 pytest 会让
整个收集以 `INTERNALERROR` 中断（2026-10-28 实测：55 个文件 0 个用例执行）。所以
`src/tests/conftest.py` 用 `collect_ignore` 把它们挡在外面，而不是让它们"看起来跑了"。

需要音频设备 / 桌面会话的用例（见 `ci.yml` 的 `SKIP` 列表、以及依赖 imagehash 的
`test_phash.py`）在 CI 上必然失败，刻意不跑——**它们需要在真机上验，不要靠 CI 判定**。

## 路线（诚实版）

已经明确**不做**的：本地模型、后台定时截图的默认开启、多槽配置摊开给用户。

还没定的两件（需要产品/成本决策，不是技术问题）：

1. **首启「她立刻能回话」的通道**：本地模型已排除，剩下「官方补贴若干条额度（要服务器中转 + 成本）」
   或「维持现状，靠承接浮层兜住」。
2. **看屏默认行为**：维持每 2s 定时抓帧（体验好、也最激进），还是改成「意图触发」为默认
   （她只在被叫到或明显需要时才看）。目前保留了隐私模式与敏感窗口跳过作为兜底。
