## 三条经验（如果只记三句）

1. **数字要么算准，要么不写。** 口径不同的两个数字并列，比没有数字更有害。
2. **判"能不能做"必须现查。** 权限、占位、CI 状态都会变；半小时前的结论就要重新核验。
3. **"查不了"不等于"没问题"。** 大仓 tree 接口失败、代理截断响应、无 git 二进制，都会伪装成"文件不存在/工作区干净"。

## 环境

工作机为 Windows + PowerShell 5.1，**无 git 二进制**，推送走 GitHub Git Data API（`gh_push.py`）。
网络到 `api.github.com` 会间歇 TLS 中断（TCP 可达但握手被重置），换域名无法绕过。
