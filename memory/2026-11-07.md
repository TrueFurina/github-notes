**本轮踩的两个 oracle 坑（假阳性规律再实例，累计已十余次）：**
1. `Bits.count(value)` 只收 bool → 数 0/1 位，**不是子串搜索**；我一开始按"子串计数"建 oracle，把 `0b000000`.count(0b000) 误判为 0。实为 `bool(0b000)=False`→数 0 位=6，正确。
2. find/split 的 oracle 边界错：针必须完整落在 [start,end) 内，合法首位是 `end-n`；我初版允许针越界 end，以及 split 用 `str(p)`（bitstring 自动 hex/bin 显示，`0x8`→`'8'`）比对，全是把 oracle 写错。
