## marl-ecdsa 第二个 bug：混合策略纳什均衡被漏报（commit `c0ba7ab`）
- `nash_verifier._find_mixed_strategy_nash` 的 `p_me` 用 `(M[1,0]-M[1,1])/denom`；对称博弈应为 `(M[0,1]-M[1,1])/denom`（即 p_opp）。当 `M[0,1]!=M[1,0]` 时算出 >1 或 0，混合均衡被漏报。
- 实测：鹰鸽 [[2,1],[3,0]] p=0.5、猎鹿 [[4,0],[3,3]] p=0.75 都被判非均衡。
- 修法：p_me 改用与 p_opp 同公式。新增 `tests/test_nash_verifier_canonical.py`（囚徒困境/猎鹿/鹰鸽三个标准博弈）；nash 相关 34 passed，全量 1777 passed。

## marl-ecdsa 第三个 bug：QMIX NumPy 回退不可复现（commit `2ba2a52`）
- `qmix.IQLEstimator` 用 `int(abs(hash(str(obs))) % hidden_dim)` 做状态离散化。Python 字符串 hash 按 PYTHONHASHSEED 随机加盐 → 同一观测跨进程落到不同 Q 表行，同 seed/config 复跑不一致。项目在 `dashboard._demo_hash` 已因同款问题改掉 hash()，qmix 回退漏了。
- 修法：新增 `_state_index` 用 sha256 前 8 字节取模；`get_action`/`train` 共用。新增跨进程回归（PYTHONHASHSEED=0/1 同索引）；全量 1779 passed。

## marl-ecdsa 第四个 bug：MAPPO critic 目标错位（commit `9878a69`）
- `mappo.train_step` 的 critic 目标用 `np.repeat(returns, n_agents)[:T]`。n_agents>1 时那是 [r0,r0,r1,...]（agent 维重复后截断），与逐时间步的 v_pred [v0,v1,v2] 错位 → critic 学到错位目标。实测 T=3,n=2: returns=[1,2,3]，ret_flat[:T]=[1,1,2]。
- 修法：抽模块级 `_critic_targets`（校验长度==T），直接用 returns。新增 `tests/test_mappo_critic_targets.py`（纯 numpy，无需 torch）；全量 1782 passed。
